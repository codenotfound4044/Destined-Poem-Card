<经济价格指南>
货币体系:
  单位: Z — 全大陆通用抽象计价单位（非实体货币），1Z为最小单位
  【强制】Z不代表任何具体单词或实体货币，严禁将Z解读或替换为任何实体货币名称。输出格式: "${数值}Z ${当地货币名}"
  定义: 跨势力商会约定的价值锚点，各国实体货币不同但统一按Z值结算
  各势力货币对照(输出时替换"当地货币名"):
    - 奥古斯提姆帝国/瓦伦蒂亚公国/萨赫拉联邦: 帝冕币
    - 兽族联盟: 兽盟币
    - 翼民圣国梵尼亚: 圣羽币
    - 精灵王庭: 星冠币
    - 诺斯加德联盟: 诺斯盾
    - 索伦蒂斯王国: 珍珠币
    - 伯伦斯法环: 各势力货币流通
  精度: 最小1Z，不可拆分，向下取整

交易原则:
  定价独立性: 物品价格仅由价格矩阵参考决定，严禁根据买方当前持有资产量动态调整。1Z购买力客观固定
  消费行为: 默认遵循理性商业逻辑(核对/找零/议价)；严禁主动放弃找零或支付不合理溢价；巨额财富仅提升支付能力上限，不改变对基础物品低廉价格的客观认知
  支付方式: 日常小额(千Z内)用硬币/纸币等现金；大额交易通过各商会/银行票据(凭票兑付)或魔法契印(魔力签押的信用凭证)结算。严禁描写角色随身掏出大量实体货币支付，超过随身现金流上限的交易必须使用票据/契印
  高阶流通: 史诗以上物品通常无法通过单纯货币购买，少数会在顶级拍卖流转，其中材料类大多受各组织/势力所垄断，此处价格仅体现价值

阶级现金流 (随身/资产极限):
  超级霸权统治者: 20万-50万 / 数千亿 (足以支持大陆级全面战争)
  区域强权统治者: 10万-20万 / 10亿-100亿+ (足以发动局部战争或建设奇观)
  独立邦国统治者: 2万-5万 / 1亿-8亿 (可负担顶级城防与传说级战略物资)
  大师工匠/大贵族: 5000-3万 / 3000万-2亿 (足以购置史诗装备)
  富商/专家工匠/低级贵族: 1000-5000 / 300万-1000万 (足以购置城市房产与稀有魔法道具)
  普通工匠/商人/中产: 100-400 / 10万-60万 (足以负担基础魔法教育)
  平民: 20-60 / 2000-5万 (仅维持吃住与极少量存款)
  奴隶/底层: 0-5 / 0 (自身即为财产)

定价排序逻辑(同品质下从下限往上限浮动):
  物品: 白板 < 词条优 < 效果极品 < 特殊效果 | 原产地 < 偏远 < 城市 < 都市 | 量产 < 匠作 < 大师 < 附魔 | 消耗品 < 轻型 < 重型 < 特殊
  任务: 采集/跑腿 < 驱逐/守卫 < 讨伐/猎杀 < 探索/决战 | 平民 < 商会 < 贵族 < 王室

  村庄400万-1500万 | 小型村镇5亿-10亿 | 中型城镇60亿-100亿 | 大型城市400亿-800亿 | 超级城市/邦国3000亿+ | 区域强权/帝国行省2万亿-3万亿 | 霸权大国10万亿-12万亿

资产结算基准:
  修正: 提高X%×(1+X%)，降低X%×(1-X%)，无修正×1；地区规则与特殊协议优先
  估值: 房产=(各层面积合计×0.25+占地面积)×所在地规模单价×类型系数(普通1/含地皮产权1.5/公寓0.75)×物价系数；设备/领地=矩阵基准价×物价系数
  经营: 年净收益=估价×收益率×收入系数(稳定5%/波动±20%，按经营状况取值，已扣人工/材料/维护)；季/月/日收益分别=年净收益÷4/12/365
  租赁: 房产月租=估价×0.5%，季/年租分别=月租×3/12；设备日租=估价×0.2%，其他周期=日租×实际天数；当地固定租金或协议价优先
  协议/税费: 应得额=周期净收益×分成比例+固定收入-固定支出；实际到账=应结收入×(1-明确税率)，无明确税率不计税
  产物: 无可靠估价时结算产物与数量，不强制折算Z
  自住: 默认无资产结算；个人消费即时结算，明确的周期收支计入资产
  取整: 代入实际数值，最终金额向下取整至1Z
