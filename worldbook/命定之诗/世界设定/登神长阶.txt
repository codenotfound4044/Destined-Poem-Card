<登神长阶>
登神路径体系:
  核心逻辑: 凡人晋升为神的唯一途径
  路径概览: 
    1. 第三层级极限 → 获取[要素] → 晋升第四层级
    2. 第四层级极限 → 融合3个要素 → 升华[权能] → 晋升第五层级
    3. 第五层级极限 → 权能融合[法则源质] → 执掌[法则] → 晋升第六层级
    4. 第六层级极限 → 依循法则完成[登神仪式] → 凝聚[神位] → 晋升第七层级
    5. 第七层级初期 → 领悟第二法则 → 开辟[神国] → 法则容纳无上限

进阶阶段详情:
  要素:
    门槛: 晋升第四层级(Lv.12→13)的必要条件
    数量限制: 晋升时需1个，第四层级上限3个
    获取方式:
      - 历史见证: 亲历重大事件后领悟
      - 汲取: 从高位物品或个体中直接汲取
    效果: 常驻被动。提供同主题强化/抗性/转化/适应；强于史诗技能，不改写现实
    状态变更: 晋升第五层级时全部清空消耗

  权能:
    门槛: 晋升第五层级(Lv.16→17)的必要条件
    来源: 将持有的3个[要素]融合升华
    数量限制: 上限1个
    状态变更:
      - 生成时: 原有的3个要素被清空，此后无需且无法再获取要素
      - 晋升时: 晋升第六层级时被清空消耗
    效果: 强力主动。短时强制局部现实按主题运转；强于传说技能，弱于法则；不可永久改写世界/概念
  
  法则源质:
    标识符: 使用༺ ༻符号包裹法则源质名称;**该标识具有唯一性，仅限[法则源质]，不包括法则以及其它任何能力或物品**
    定义: 沟通权能与法则的桥梁，世界根本规则的具现
    获取方式:
      - 特殊继承: 掌握特殊继承仪式的第六层级强者，将自身法则凝聚后传给继承人(施予者必死，通常用于大国或大组织延续力量)
      - 掠夺: 彻底击杀第六层级强者，并在其未自毁法则的情况下获取
      - 探索: 在位面与虚海交界特殊区域寻找位面诞生之初的无主法则源质(极少见)
    强制固定格式(物品):
      名称: ༺${法则源质名称}༻
      品质: 神话
      类型: 消耗品
      标签: [法则源质]
      效果: 仅可用于与权能融合为法则，融合后消失
      描述: ${叙事描述}

  法则:
    门槛: 晋升第六层级(Lv.20→21)的必要条件
    来源: 将[权能]与[法则源质]融合，洞悉世界的根本真理
    数量限制: 第六层级极限为1条
    状态变更: 生成时，原有的权能与法则源质被清空，此后无需且无法再获取
    晋升异象:
      - 视觉: 晋升地点周边出现大范围魔力异象(天候异变、元素失衡等)
      - 感知: 同位面所有第六层级强者皆可感应到有人晋升，但无法知晓具体身份
    效果: 终极能力(被动+主动)。可大范围改写现实与概念；强于神话技能，弱于神位；不可脱离自身主题

  神位:
    门槛: 晋升第七层级(Lv.24→25)的必要条件
    来源: 以[法则]为基，完成[登神仪式]后凝聚
    晋升异象: 整个位面产生宏大异象，所有生灵都能感知到新神诞生
    转化: 种族转化为神明
    效果: 领域主宰。对相关领域具统治权/解释权/压制权；高于法则，但仍受神职与领域约束

神祇进阶与神国:
  进阶路线:
    1. 新晋神明: 拥有神位，持有1条法则
    2. 巩固: 自行领悟第2条法则
    3. 质变: 拥有2条法则后，可消耗力量开辟[神国]
    4. 巅峰: 拥有神国后，打破法则容纳数量限制，获取数量无上限
  神国:
    效果: 神域延伸。于神国内具近乎绝对掌控权，可制定基础规则；高于神位，受神国边界限制
  神国权能:
    - 独立位面: 于虚海中开辟的专属世界
    - 全知全能: 领域内获得绝对掌控权
    - 规则定制: 自由修改物理常数、时间流速等基础规则

登神仪式:
  定义: 以世界为舞台、法则为核心的终极试炼
  流程:
    1. 资格: Lv.24极限 + 执掌一道完整法则
    2. 宣告: 向世界宣告开启，全大陆势力可能强制卷入
    3. 践行: 根据法则特性，以凡人之躯完成神之伟业，产生影响整个位面的后果
  示例:
    - 战争法则: 主导并彻底赢得一场改变世界格局的战役
    - 生命法则: 在死寂绝地创造完整生态与新智慧种族
