# 古风词汇清理

长楼层游玩时，模型会被提示词里的修仙话术和半文言句式带偏，西幻逐渐变成古风。这份记录写清已经改了什么、按什么规则改、还剩哪些没改，方便下次接着做。

## 改写规则

1. 文言虚词换白话：于→在/从，其→它的/他们的，皆→都，亦→也，乃→是；"位于""建于""死于"这类现代常用搭配保留。
2. "X 掌 Y"改为"X 负责 Y"；"此岭""一峰""设于此峰"等山水腔改为"这座山岭""一座山峰"。
3. 只拆文言味的四字格（"月夜尤澈""循山道"），信息型短语（"政治中立，平等自由"）保留。
4. 中式计量和时间换掉：丈→米，步→米，里→公里，晨昏→清晨和黄昏/早晚，时辰→时刻。
5. 专名可以改，但要同步 `worldbook/命定之诗.yaml` 的条目名、关键词、文件路径，以及 `content/catalogs/` 里的引用；会写进存档的地点名（如开局地点路径）不改，除非同时在 CHANGELOG 记【不兼容】。
6. 本来就是东方设定的内容不动：蝾螈王朝与天镜湖湿地、东方龙裔、千爻、龙娘傲雪、读者核心的汉服/旗袍形态。

### 排查方法

用词表统计各文件的古风词频，再用正则统计"X 掌 Y"、"于"当"在"、"皆/亦/乃"、"世代/历代/自古"、四字排比等句式，按每千字命中数排序；排除东方设定文件。之前的脚本没有入库，下次可以照这个思路重写，或者直接让 Claude 重新跑一遍。

### 其他

- 全书零散的"于""其"文言用法约 400 处，单个文件浓度低，建议改到某个文件时顺手处理，不做全量替换。
- 地理数据（已核实，不用改）：`content/geography/places.yaml` 里地点的 `description.brief/detail` 会被常驻条目《长途移动与地理参考》读进提示词，但 161 个地点的描述只命中 4 处"建于""隐匿于"这类现代常用搭配。"吾辈""半个时辰"等词在地图标记 `marker.description` 里，只在前端地图上显示，不进提示词；想统一风格时可以再改。
- 输出端正则：参考外部正则包"古法杀古风"挑一组不误伤本卡的替换（掌柜、小二、客官、一刻钟、时辰、半晌、莫要、何须、床榻、大氅、修为、神通、阵法、文牒/路引、恩准、屏退、请安、龙椅、龙袍等），放进 `card/regex/index.json`。不要照搬"回路→空""金币→帝冕币""小的→我"这类会破坏设定或误伤普通词的规则。
- 《祂的命定之囚》DLC 目前没有接入世界书 YAML，里面的"神识"已改为"意识"，接回时会一起生效。
