# 提示词写作与古风清理

提示词使用自然、清楚的现代汉语，保持西幻语境。本页维护写作与审校规则，后半部分记录古风清理进度。

## 改写规则

1. 文言虚词按语境换成白话：于→在/从，其→它的/他们的，皆→都，亦→也，乃→是；"位于""建于""死于""其中"等现代常用搭配保留。
2. "X 掌 Y"改为"X 负责 Y"；"此岭""一峰""设于此峰"等山水腔改为"这座山岭""一座山峰"。
3. 只拆文言味的四字格（"月夜尤澈""循山道"），信息型短语（"政治中立，平等自由"）保留。
4. 距离用米/公里，时间点用"时刻"，时长用小时等单位，按设定换算并保留原意；晨昏可写清晨和黄昏/早晚。
5. 专名默认保留；改名时同步 `worldbook/命定之诗.yaml` 的条目名、关键词、文件路径和 `content/catalogs/` 引用。涉及存档地点名时遵循项目兼容规则，并在 CHANGELOG 记【不兼容】。
6. 本来就是东方设定的内容不动：蝾螈王朝与天镜湖湿地、东方龙裔、千爻、龙娘傲雪、读者核心的汉服/旗袍形态。
7. “凡人”可用于与神灵、不朽生命的对照，也可保留在角色口吻或明确的东方文化中；描述具体种族、普通居民或实力时按实际含义用词。
8. 超凡力量由虚海源能(简称“源能”)在位面内依当地法则转化而来；各体系按角色、族群和传承划定范围，以技能呈现。禁止使用“血气”“斗气”“以太”称呼；非东方设定禁用古风、武侠、修仙类称呼。

## 日常写作与审校

检查完整段落里的修仙话术、半文言句式和成串的山水腔，结合下方保留项判断。

西幻中文可采用译作中略正式、具体的叙述。设施、机构按用途和文化背景自然命名，句子写清行动主体；宗教与工艺描写保留设定依据，避免用雅字重新拼出宗门式名称。改写示例：

| 原写法 | 建议写法或判断 |
| --- | --- |
| 生命层级突破到了…… | 生命层级晋升到了……；"突破封锁"是正常用法 |
| 此地由议会掌商贸，亦管税赋 | 这里的商贸和税收都由议会负责 |
| 贵族角色使用古风措辞 | 贵族角色使用古典贵族式措辞，再写清礼仪、态度和说话习惯 |
| 金穗承阳，无惧凛冬 | 势力格言文体，按现有设计保留 |
| 淬霜池 | 冰泉淬火池，直接交代水源与工艺用途 |
| 净尘居：住所负责净化仪礼 | 工坊宿舍；住在里面的工匠负责净化仪式与日常维护 |
| 能量（魔力/血气）凝练 | 超凡力量的承载、运用与生命跃迁，具体表现由角色与技能决定 |

### 精简提示词

- 合并同一轮上下文里含义相同的提醒；独立激活条目保留各自需要的说明，以及不同的条件、对象和例外。
- 把"必须、务必、再次强调"的堆叠改成一条具体要求，写清条件、动作和输出即可。
- 防错要求以实际约束或已知问题为依据，删去没有具体作用的兜底、自查和确认步骤；保留实际生效条件、输出格式和变量写入要求。

AI 助手使用 [prompt-style](../.agents/skills/prompt-style/SKILL.md)，例如："按 prompt-style 检查本次提示词改动。"

## 输出端正则「[去古风]」

世界书只管模型读到的设定，模型自己写出的"掌柜""时辰""修为"会留在历史楼层里越积越多。`card/regex/optional/去古风.json` 是 48 条「[去古风]」规则的合集，开启后在显示和发送给模型时把这些词换掉，存档原文不变。

这个合集目前只放在仓库里，没有装配进卡（卡只读 `card/regex/index.json`），要不要放进卡以后再定。

- 使用方法：在酒馆「正则」面板点导入，选这个 JSON 文件（锁定的 SillyTavern 支持一次导入整个数组）。规则默认全部关闭，导入后勾选需要的规则，或全选后批量启用。
- 以后要放进卡：把这些条目追加到 `card/regex/index.json` 末尾，前十条顺序不动，同时把 `tests/card-source.test.mjs` 里的正则条数改掉。同步工具（`tools/sync/receiver.mjs`）已经按「十条基础正则 + 任意条「[去古风]」正则」校验，推送时会保留酒馆里对这些规则设好的开关。
- 只作用于 AI 输出（placement 2），`markdownOnly` 和 `promptOnly` 都开，`runOnEdit` 关。
- 东方设定的剧情（蝾螈王朝、东方龙裔等）里这些词也会被替换，玩这类剧情时可以关掉。
- 对话美化脚本（AutoDialogueBeautifier）只管理它自己目录里的规则名和「命定核心-」等美化前缀，不会改这些规则的开关。
- 参考了外部正则包"古法杀古风"，但没有照搬会破坏本卡设定或误伤普通词的规则：回路→空（伯伦斯法环的"魔力回路"）、金币/银币→帝冕币（别家货币）、斗气/以太→魔力（会覆盖角色和技能各自的能力来源）、小的/在下/本王/俺/老子→我（误伤"小小的""在下面"，也抹掉角色口吻）、脉络→魔力通道（误伤"事件脉络"）、灵性→空、营生→生计、冷笑→乐、手印→指纹。外部包里"大理寺"一条写法有误不生效，"炼化"一条查的和换的都是"转化"。
- 增删规则时，在 `tests/optional-regex.test.mjs` 的例句表里同步：每条规则都要有一个应命中的例句和一个相邻但不应命中的例句（比如"阵眼"不能误换"一阵眼花"，"识海"不能误换"意识海"，"神魂"跳过"神魂颠倒"），再在世界书正文里搜一遍，确认不会改掉本卡自己的设定词。
